Senzing Agentic AI Bootcamp

Senzing Bootcamp for ChatGPT

From nothing installed to a running bootcamp, in seven steps.

The ChatGPT bootcamp runs in the Codex desktop app from OpenAI, not in the ChatGPT chat window. Install the plugin in Codex.

Get started

New to the bootcamp? Start at hub.senzing.com/bootcamp

Before you start

What you need

  • A ChatGPT Pro plan. A ChatGPT Plus plan also works, across several 5-hour windows, but not in one session.
  • Network access to the Senzing MCP server (https://mcp.senzing.com/mcp). The bootcamp cannot proceed without it. On a corporate network or VPN, ask for the domain mcp.senzing.com to be allowed.
  • Python 3, available as python3 on the PATH. The bootcamp’s hooks and its graduation recap run on it. On Windows, if only python or py is installed, add a python3 entry to the PATH.
  • A new, empty folder for the bootcamp.
  • Recommended A business problem and 5,000 to 20,000 records. A problem that needs entity resolution, and records that illustrate it. Recommended, not mandatory.

Install and start

Seven steps to a running bootcamp

  1. Install Codex

    Download and install Codex from chatgpt.com/codex.

  2. Configure Codex

    Add this block to ~/.codex/config.toml. Create the file if it does not exist.

    ~/.codex/config.toml

    [experimental_network]
enabled = true
allow_local_binding = true

    The bootcamp runs local web servers for its visualizations, and this setting allows them.

  3. Open the Codex desktop app

    Open the Codex desktop app you installed in step 1.

  4. Select model and effort

    In the lower right of Codex:

    1. Choose the model GPT-5.6 Terra.
    2. Choose the effort Medium.

  5. Create a project

    1. In the left-hand navigation bar, to the right of Projects, click +.
    2. In the Create project dialog, for the project name, enter Senzing Bootcamp.
    3. For the source folder, choose your new, empty folder.
    4. Click Create project.

  6. Install the plugin

    1. In the left-hand navigation bar, click Plugins.
    2. In the upper right of the Plugins panel, click Add.
    3. Click Add a marketplace.
    4. In the Add plugin marketplace dialog, for Source, enter https://github.com/Senzing/senzing-bootcamp-chatgpt-plugin.
    5. Click Add marketplace.
    6. In the Plugins panel, choose the Personal tab.
    7. Click Senzing Bootcamp.
    8. In the Senzing Bootcamp panel, click Install plugin.
    9. Click Try now.

  7. Start the bootcamp

    With the Senzing Bootcamp project selected, enter this in Codex’s agentic chat:

    Codex agentic chat

    Start the Senzing Bootcamp

What happens next

The bootcamp takes it from here

The bootcamp first asks you to choose your curriculum, level of detail, and programming language. Then it guides you through the bootcamp, module by module. See every module.

Tips

Get the most from the bootcamp

Model and effort

GPT-5.6 Terra at Medium, as set in step 4. At the start of each module the bootcamp may suggest a different model or effort. Change it with the controls in the lower right.
